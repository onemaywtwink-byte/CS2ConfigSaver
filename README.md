# CS2 Config Saver

Сохраняет и возвращает конфиг CS2: бинды, настройки, видео, autoexec.cfg.
Запуск: Python 3.9+, `run.bat`. Один .exe: `build_exe.bat`. Тесты: `python test_core.py`.

Интерфейс открывается отдельным окном (Edge или Chrome в режиме приложения, иначе вкладка браузера).
Сервер слушает только 127.0.0.1 и принимает запросы с одноразовым токеном. Программа закрывается сама,
когда вы закрываете её окно (или через меню ⋯ → «Выйти»).

1. Выберите аккаунт Steam сверху.
2. «Сохранить»: копия в `%USERPROFILE%\CS2ConfigSaver\profiles`. Можно отметить только бинды, только настройки, видео, autoexec.cfg (все .cfg из папки игры включаются отдельной галочкой). Названия на «auto-backup» зарезервированы.
3. Вкладка «Бинды»: схема клавиатуры и мыши, «Сохранить только бинды», «Перенести бинды на другой аккаунт», «Скачать как .cfg». У профиля есть «Применить только бинды».
4. «Сборка .cfg»: отметьте нужные бинды и настройки (можно с разных аккаунтов и профилей, выбор не сбрасывается), допишите свои команды, задайте имя. «Записать в игру» кладёт файл в `csgo/cfg` (старый сохраняется как .bak), «Скачать» отдаёт его в «Загрузки». В игре: `exec имя`, для автозагрузки параметр запуска `+exec имя`.
5. «Восстановить»: части выбираются отдельно (бинды, настройки, видео, autoexec). Проверки идут до записи, затем автобэкап (↺, 10 последних; пользовательские профили не удаляются). Если запись сорвётся, каждый затронутый файл возвращается к прежнему содержимому, а созданные операцией удаляются.
6. «Сравнение»: что изменится в биндах, настройках, системных настройках и видео.
7. autoexec.cfg: пустой текст файл не создаёт; старый файл сохраняется как .bak (первый .bak с оригиналом не затирается, датированных хранится 4).
8. Экспорт ZIP по умолчанию убирает ID аккаунта и заметку. Импортированные профили помечены, файлы для папки игры по умолчанию не отмечены.

Закройте CS2 (лучше и Steam) перед восстановлением. Если Steam спросит, какую версию взять, выберите локальную. Ошибки дописываются в `%USERPROFILE%\CS2ConfigSaver\error.log`.
